# Bitcoin: A History in Motion

Scroll-driven interactive history of Bitcoin (2008 → 2026), EN/VI. Live at `/btc/` on this site.

- Next.js (static export) · TypeScript · Tailwind v4 · GSAP ScrollTrigger · React Three Fiber · SVG · Framer Motion
- Price, hashrate and supply: Coin Metrics community data (CC BY-NC 4.0) to 23 May 2026, then dated news reports.

```bash
npm install
NEXT_PUBLIC_BASE_PATH=/mi-a7k2x9/btc npx next build   # → out/, copied to ../public/btc
```
